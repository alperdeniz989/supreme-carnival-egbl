# کتابخانه دیجیتال حسین اقبالیان

پروژه Android Studio برای نسخه اول اپ کتابخانه دیجیتال.

## ساخت APK
1. Android Studio را باز کنید.
2. گزینه **Open** را بزنید و این پوشه را انتخاب کنید.
3. صبر کنید Gradle Sync کامل شود.
4. از منوی **Build → Build APK(s)** استفاده کنید.
5. APK معمولاً در مسیر زیر ساخته می‌شود:
   `app/build/outputs/apk/debug/app-debug.apk`

## نکته
محتوای فعلی WebView از نمونه نسخه سوم پروژه گرفته شده است. برای انتشار تجاری، متن کامل دو کتاب، پرداخت، احراز هویت و حفاظت از محتوا باید به نسخه نهایی اضافه شود.
